# 나의 치이카와 타입 찾기

16개 일상 질문 → 7개 캐릭터 매칭 → 답변 근거와 성향 표시 → 한글 PNG 결과 카드 다운로드.
로그인, API 키, 데이터베이스가 필요 없는 Streamlit 앱입니다.

## 시작하기

Python 3.10 이상을 권장합니다. ZIP을 먼저 압축 해제한 다음 VS Code에서
이 README와 app.py가 있는 chiikawa_app 폴더를 엽니다.
터미널의 현재 위치가 해당 폴더인지 확인하고 다음을 실행하세요.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 표시된 Local URL로 접속하세요.
보통 http://localhost:8501 입니다. 종료는 터미널에서 Ctrl+C입니다.
Windows에서 python 명령이 없고 py 명령이 있다면 두 명령의 python을 py로 바꾸세요.
macOS에서는 설치 환경에 따라 python3를 사용하세요.

## 포함 파일

- app.py: 질문, 캐릭터 기준, 점수 계산, 화면 및 PNG 생성 코드
- requirements.txt: 실행 패키지
- .streamlit/config.toml: 파스텔 테마
- assets/characters/: 치이카와·하치와레·우사기·모몽가·쿠리만쥬·랏코·시사 이미지
- assets/NanumGothic.ttf: PNG 한글 표시용 폰트
- assets/FONT-LICENSE.txt: 동봉 폰트 라이선스
- test_app.py: 점수 계산 및 사용자 흐름 검사

assets 폴더를 함께 보관해야 결과 카드를 만들 수 있습니다.
첨부 ZIP의 7개 소개 이미지를 assets/characters에 포함했습니다. 결과 화면, 두 번째 캐릭터 펼침 영역, 다운로드 PNG에 연결됩니다. 소개 이미지의 글씨와 원래 비율은 보존합니다.

## 수정 위치

app.py의 RAW_QUESTIONS에서 질문과 선택지를 바꿀 수 있습니다.
각 질문의 4개 선택지는 해당 성격 축의 낮은 값부터 높은 값 순서입니다.
화면에서는 위치를 순환해서 표시합니다.
각 축당 2문항이며, 보기 점수 0~3을 더하고 가능한 최대 점수로 나누어 0~100으로 환산합니다.
CHARACTERS의 vector는 AXES 순서에 맞춘 캐릭터 기준값입니다.
8개 축에 같은 가중치를 적용한 제곱거리로 비교합니다.
정확히 동점인 캐릭터는 모두 안내하며, 첫 카드는 데이터의 표시 순서로 결정합니다.
대표 결과의 근거는 해당 캐릭터 기준에 가까운 실제 선택지 3개를 서로 다른 축에서 뽑습니다.
일치 확률이나 검사 정확도를 의미하지 않습니다.

## 동작과 제한

- 답변 수정: 이전 버튼 또는 결과 화면의 답변 수정하기를 사용하세요.
- 재시작: 다시 테스트하기는 현재 답변과 닉네임을 지웁니다.
- 답변은 세션 메모리에만 보관합니다. 새로고침·연결 종료 후 복구하지 않습니다.
- 캐릭터별 성격값과 결과 문구는 제작자의 해석입니다. 공식 성격 진단이 아닙니다.
- 한글 폰트는 포함되어 있습니다. 일부 특수문자·이모지 닉네임은 PNG에서 표시되지 않을 수 있습니다.
- 공유는 PNG 저장과 배포 주소 전달 방식입니다. 자동 SNS 게시나 클립보드 복사는 포함하지 않습니다.
- 문항·기준값은 초기 버전입니다. 실제 응답자 피드백으로 편향과 결과 쏠림을 조정하세요.

## 이미지 적용 버전 변경 사항

- 기존 12문항에 목표 유지 2문항과 학습 방식 2문항을 추가해 총 16문항입니다.
- 성향 축은 6개에서 8개로 확장했습니다. 각 축은 2문항으로 동일하게 측정합니다.
- 시사는 첨부 소개의 성실함·꾸준한 공부·존경하는 본보기로부터 배우는 태도를 반영했습니다.
- 랏코는 책임과 주도성, 시사는 꾸준한 학습과 본보기 선호로 구분하도록 기준을 설계했습니다.
- 7개 캐릭터 모두 기준에 가까운 응답에서 대표 결과로 선정되는지 검사합니다.
- 결과 이미지는 원본 소개 카드 전체입니다. 캐릭터만 따로 잘라내지 않습니다.
- PNG 카드 크기는 1080×1900입니다.
- 기존 버전 사용 중 업데이트하면 문항 수 변경을 감지해 진행 중 답변을 초기화합니다.

기존 실행을 Ctrl+C로 종료하고, 새 ZIP을 별도 폴더에 압축 해제한 뒤 실행하는 것이 가장 간단합니다.
